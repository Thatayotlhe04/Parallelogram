The linter for
fine-tuning data.

Parallelogram checks your dataset before you spend GPU hours on it. If it exits 0, your training run won't fail because of data.

$ pip install parallelogram

Works with  OpenAI chat JSONL · ShareGPT · prompt/completion · Axolotl · TRL · Unsloth · tiktoken · Hugging Face tokenizers · GitHub Actions

Six checks for failures
your trainer won't catch.

  • schema

    Malformed JSONL, missing fields, wrong types. Can't be disabled.

    ERROR

  • roles

    Doubled turns, misplaced system prompts, conversations that end on the user.

    ERROR

  • empty-content

    Blank turns that teach the model silence.

    ERROR · FIXABLE

  • duplicates

    Repeated records that push the model toward memorizing.

    ERROR · FIXABLE

  • context-window

    Records over your token budget, which TRL truncates without telling you.

    ERROR · FIXABLE

  • encoding

    BOM markers and mojibake that end up in the weights.

    WARNING · FIXABLE

Check. Fix. Gate.

  1. 01 check

    parallelogram check data.jsonl

    Every issue, with its line number and rule. Exits 0, 1 or 2.

  2. 02 fix

    parallelogram check data.jsonl --fix --output clean.jsonl

    Mechanical repairs, then a re-check. Anything still broken is dropped, with the reason.

  3. 03 gate

    parallelogram report data.jsonl --baseline main.json

    Fails the pull request when dataset quality regresses (exit 3).

FAQ

What does “exits 0” guarantee?

With all rules on: every record parses, has a valid role order ending on the assistant, has no empty turns or exact duplicates, and fits your token budget (counted exactly with --tokenizer, estimated otherwise). It checks that your data will train, not that it's good data.

Does my data leave my machine?

No. Nothing is uploaded and there is no telemetry. The only network request is opt-in: --tokenizer may download a tokenizer vocabulary once, then caches it.

Which formats?

OpenAI/Qwen chat JSONL, ShareGPT and prompt/completion, detected per line.

Are token counts exact?

With pip install 'parallelogram[tokenizer]' and --tokenizer, yes (tiktoken or Hugging Face). Without, counts are estimated and overflows are warnings, never errors.

Is it free?

Yes. Apache-2.0, on PyPI and GitHub.
