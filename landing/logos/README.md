# Logos for the "Works with" strip

Drop the official logo files here with these exact names. The strip on
parallelogram.dev appears automatically once three or more of them load;
any that are missing are simply left out.

| File | Project |
| --- | --- |
| `openai.svg` | OpenAI |
| `qwen.svg` | Qwen |
| `hugging-face.svg` | Hugging Face |
| `axolotl.svg` | Axolotl |
| `unsloth.svg` | Unsloth |
| `llama-factory.svg` | LLaMA-Factory |
| `github-actions.svg` | GitHub Actions |

Use each project's official logo from its own brand or press page (or its
repository), and follow that brand's usage rules. SVG is best; the page
renders them 22px tall, grey, and in full colour on hover. A wordmark (logo
plus name) reads better than a bare icon.
